## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability, please report it responsibly.

### How to Report

**DO NOT** open a public GitHub issue for security vulnerabilities.

Instead, please report security vulnerabilities by emailing:

**security@example.com** (Replace with actual email)

### What to Include

Please include the following in your report:

1. **Description**: Clear description of the vulnerability
2. **Impact**: Potential impact and attack scenarios
3. **Reproduction**: Step-by-step instructions to reproduce
4. **Evidence**: Screenshots, logs, or proof-of-concept code
5. **Suggestion**: Your recommendation for fixing the issue

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial Assessment**: Within 1 week
- **Resolution Target**: Within 30 days (depending on complexity)

### What to Expect

1. **Acknowledgment**: We'll confirm receipt of your report
2. **Assessment**: We'll evaluate the vulnerability and its impact
3. **Fix**: We'll develop and test a fix
4. **Disclosure**: We'll coordinate disclosure with you
5. **Credit**: We'll credit you in the security advisory (unless you prefer anonymity)

## Security Proven Patterns for Users

When using this repository:

1. **Verify Links**: Always verify external links before clicking
2. **Check Tools**: Research tools before installing or using them
3. **Update Regularly**: Keep your tools and dependencies updated
4. **Use Official Sources**: Download tools from official websites only
5. **Read Reviews**: Check tool reviews and community feedback

## Scope

This security policy covers:

- The repository content itself
- Links to external resources
- Recommended tools and services

This security policy does NOT cover:

- Third-party tools mentioned in the repository
- External websites linked from the repository
- Your own video creation workflows

## Safe Tool Usage

When following skills in this repository:

1. **Research tools** before installing (check reviews, official sites)
2. **Use free tiers** before committing to paid plans
3. **Check privacy policies** of recommended services
4. **Backup your work** before using new tools
5. **Keep credentials secure** (never share API keys)
