# Script Writing Skill

> Transform ideas into compelling video scripts with AI assistance.

## When to Use

- Starting a new video project from scratch
- Converting blog posts or articles into video format
- Creating educational or tutorial content
- Writing narration for B-roll heavy videos
- Developing series with consistent voice and structure
- Repurposing existing content for different formats

## Workflow

### Step 1: Define Your Video Parameters

Before prompting AI, establish these fundamentals:

```markdown
**Video Type:** [Tutorial / Explainer / Story / Review / Vlog]
**Target Length:** [Short <3min / Medium 3-10min / Long 10-20min]
**Audience:** [Beginners / Intermediate / Advanced / General]
**Platform:** [YouTube / TikTok / LinkedIn / Course]
**Tone:** [Professional / Casual / Humorous / Educational]
```

### Step 2: Generate the Hook (First 30 Seconds)

The hook determines if viewers stay. Use this prompt structure:

```markdown
Write a video script hook for a video about [TOPIC].

Requirements:
- Open with a bold claim, question, or surprising fact
- Create curiosity gap within first 10 seconds
- Preview what the viewer will learn/achieve
- Match tone: [casual/professional/energetic]
- Include a visual direction note for each line

Example structure:
[0-5s] Pattern interrupt
[5-15s] Problem/pain point
[15-30s] Promise/solution preview
```

### Step 3: Build the Script Body

Use the **Problem-Agitate-Solve-Prove** framework:

```markdown
Expand this outline into a full video script:

TOPIC: [Your topic]
OUTLINE:
1. Hook (already written)
2. Problem context - why this matters
3. Common mistakes people make
4. The solution/method (main content)
5. Proof/examples
6. Call to action

Rules:
- Write for spoken word, not reading
- Include [B-ROLL: description] notes for visual breaks
- Add [TRANSITION] markers between sections
- Keep sentences under 20 words
- Use "you" language, not "we" or "one"
- Include engagement checkpoints every 2-3 minutes
```

### Step 4: Add Engagement Patterns

Inject these elements throughout:

```markdown
Review this script and add engagement patterns:
1. Open loops (tease upcoming content)
2. Rhetorical questions every 60-90 seconds
3. "But here's the thing..." style transitions
4. Micro-summaries after complex sections
5. Direct address ("If you're thinking...")
6. Specific numbers and examples (not vague claims)
7. Pattern interrupts every 3-4 minutes
```

### Step 5: Format for Production

```markdown
Reformat this script for video production:

Add:
- Timestamp estimates for each section
- Visual direction in [BRACKETS]
- Emphasis markers on key phrases (CAPS or *asterisks*)
- Natural pause points marked with [...]
- B-roll suggestions every 30-45 seconds
- Lower third/title card suggestions
- Music/sound effect cues in (parentheses)

Remove:
- Complex sentences that are hard to speak
- Technical jargon without explanation
- Passive voice constructions
```

## Templates

### Tutorial Script Template

```markdown
# [Title]

## HOOK [0:00 - 0:30]
[Visual: Screen recording ready]
Narrator: "Did you know that [surprising stat]? In this video,
I'll show you exactly how to [achieve result] in [timeframe]."
[TEXT ON SCREEN: "How to [Result]"]

## INTRO [0:30 - 1:00]
Narrator: "Before we dive in, let me show you what we're
building today." [DEMO PREVIEW]
Narrator: "By the end, you'll have [specific deliverable]."

## SECTION 1: [Topic] [1:00 - 3:00]
Narrator: "Let's start with [first step]."
[B-ROLL: Screen recording of process]
Key Point: [Core concept]
Example: [Concrete demonstration]
Checkpoint: "Does that make sense? Let's move on."

[...continue for each section...]

## CTA [Final 30s]
Narrator: "If this helped, hit subscribe. Next week,
I'm covering [teaser]. Link in the description."
[END SCREEN with subscribe button]
```

### Storytelling Script Template

```markdown
# [Title - Curiosity-Driven]

## COLD OPEN [0:00 - 0:15]
[Visual: Dramatic shot]
"In [year], [person/company] did something no one expected..."

## SETUP [0:15 - 2:00]
[Establish context and normal world]
[Visual: Relevant footage/images]

## CONFLICT [2:00 - 4:00]
[What went wrong / challenge faced]
[Build tension with pacing]
[Visual: Contrasting imagery]

## RESOLUTION [4:00 - 7:00]
[How the challenge was overcome]
[Lessons learned]
[Visual: Success imagery]

## LESSON [7:00 - 8:00]
[Universal takeaway for viewer]
[Actionable application]

## CTA [8:00 - 8:30]
[Connect lesson to subscribe/next video]
```

## Pitfalls

### Common Mistakes

1. **Writing for eyes, not ears** - Scripts should sound natural when spoken aloud
2. **No breathing room** - Overloading with information without pauses
3. **Weak hooks** - Starting with "Hey guys, welcome to my channel..."
4. **Burying the lead** - Taking too long to get to the value
5. **No visual variety cues** - Script plays over static talking head
6. **Ignoring platform norms** - Same script for YouTube Shorts and 20-min tutorials
7. **Perfect grammar trap** - Spoken language is naturally more fragmented

### Quality Checks

- [ ] Read the script aloud - does it sound natural?
- [ ] Time the hook - does it grab attention in under 10 seconds?
- [ ] Check engagement points - is there variety every 2-3 minutes?
- [ ] Verify visuals - is something happening on screen throughout?
- [ ] Test with TTS - any tongue-twisters or awkward phrases?
- [ ] Review length - match target runtime?

## Pro Tips

1. **Script in beats, not paragraphs** - Each beat is one idea, one visual, 15-30 seconds
2. **Write the thumbnail/title first** - It clarifies the core promise
3. **Record a voice memo first** - Talk through the topic naturally, then refine
4. **Use "So what?" test** - After every section, ask "so what?" If unclear, rewrite
5. **Script the rewatch** - Add moments that reward viewers who watch twice
6. **Front-load value** - Best content in first 60% of video
7. **Leave room for personality** - Mark spots for ad-libs and improvisation

## 中文版本

### 何时使用

- 从零开始新视频项目
- 将博客文章转换为视频格式
- 创建教育或教程内容
- 为B-roll视频编写旁白
- 开发具有统一风格的系列内容
- 将现有内容改编为不同格式

### 工作流程概要

1. **确定视频参数** - 类型、时长、受众、平台、语调
2. **生成钩子** - 前30秒决定观众去留
3. **构建主体** - 使用"问题-激化-解决-证明"框架
4. **添加互动元素** - 开环、反问、总结、直接对话
5. **格式化输出** - 添加时间戳、视觉指引、音效标记

### 常见陷阱

- 书面语而非口语化表达
- 信息过载，缺乏停顿
- 钩子不够吸引人
- 未能根据平台调整脚本

### 专业建议

- 用节拍而非段落来编写脚本
- 先写缩略图和标题来明确核心承诺
- 先录制语音备忘录，再精炼成脚本
- 每个部分通过"所以呢？"测试
