# Storyboarding Skill

> Plan video visuals shot-by-shot with AI-assisted storyboarding.

## When to Use

- Planning visual sequences before filming
- Communicating video concepts to clients or team members
- Designing complex multi-camera or animation sequences
- Pre-visualizing B-roll needs for documentary or vlog content
- Creating shot lists for scripted content
- Planning motion graphics and visual effects sequences

## Workflow

### Step 1: Break Down the Script into Scenes

```markdown
Analyze this script and break it into visual scenes:

SCRIPT: [paste script]

For each scene, provide:
1. Scene number
2. Time range (start-end)
3. Narration/dialogue for this section
4. Primary visual type (talking head / screen recording / B-roll / graphic)
5. Camera angle suggestion
6. Lighting/mood keywords
7. Duration in seconds
```

### Step 2: Generate Shot Descriptions

```markdown
For each scene, create detailed shot descriptions:

Scene: [scene number and description]
Duration: [X seconds]

Generate:
- Wide shot description (establishing context)
- Medium shot description (main action)
- Close-up detail shots (2-3 options)
- Transition type to next scene
- Any text overlay or graphic needs
- Sound design notes
```

### Step 3: Create Visual Storyboard

```markdown
Create a storyboard with [number] frames for this video:

TOPIC: [topic]
STYLE: [Realistic / Animated / Mixed / Screencast]

For each frame, provide:
```

| Frame | Time | Shot Type | Description | Camera Move | Audio | Notes |
|-------|------|-----------|-------------|-------------|-------|-------|
| 1 | 0:00-0:05 | Wide | Person at desk, morning light | Slow zoom in | Music fade in | Establish setting |
| 2 | 0:05-0:15 | Medium | Presenter looks at camera | Static | Dialog starts | Direct address |
| 3 | 0:15-0:25 | B-Roll | Screen recording of software | Pan right | Narration continues | Show don't tell |

### Step 4: Plan B-Roll and Cutaways

```markdown
Generate a B-roll shot list for this video:

For each section that needs visual support:
1. What concept needs illustration?
2. 3 specific B-roll shot ideas (be very specific)
3. Where to source: stock footage / custom filming / screen capture
4. Duration needed
5. Suggested stock footage search terms

Organize by filming location/session for efficient production.
```

### Step 5: Plan Transitions and Effects

```markdown
Design the transition and effects plan:

For each scene boundary:
1. Transition type (cut / dissolve / swipe / custom)
2. Duration of transition
3. Any motion graphics needed
4. Lower third / title card needs
5. Sound effect for transition

Also plan recurring visual elements:
- Channel watermark placement
- Subscribe animations
- Chapter markers
```

## Pitfalls

### Common Mistakes

1. **Too many shots** - Over-editing kills pacing; not every sentence needs a cut
2. **Ignoring continuity** - Clothing, props, and lighting must match across shots
3. **Static storyboards** - Plan for camera movement, not just static frames
4. **Missing reaction shots** - Plan cutaway reactions for interviews
5. **B-roll mismatch** - Generic B-roll that doesn't illustrate the specific point
6. **No establishing shot** - Jumping straight to close-ups without context
7. **Forgetting the hook visual** - Planning the script hook but not the visual hook

### Quality Checks

- [ ] Does every scene have a clear visual purpose?
- [ ] Are transitions planned between all scenes?
- [ ] Is there visual variety (no more than 15 seconds same shot)?
- [ ] Are B-roll shots specific enough to source/produce?
- [ ] Does the opening frame grab attention?
- [ ] Are text overlays accounted for in each frame?

## Pro Tips

1. **The 3-second rule** - Change something on screen every 3 seconds (angle, graphic, B-roll)
2. **Layer your visuals** - Talking head + background + overlay + animation = rich frames
3. **Storyboard the audio too** - Music, SFX, and silence are visual storytelling partners
4. **Plan for vertical AND horizontal** - Shoot wider, crop later; plan both in storyboard
5. **Color-code shot types** - Use a legend: blue=talking head, green=B-roll, orange=graphics
6. **Include mood references** - Link to reference videos for each section's vibe
7. **Time your beats** - Read narration aloud and mark natural visual change points

## 中文版本

### 何时使用

- 拍摄前规划视觉序列
- 向客户或团队传达视频概念
- 设计复杂的多机位或动画序列
- 预可视化纪录片或Vlog的B-roll需求
- 为脚本内容创建镜头清单
- 规划动态图形和视觉效果序列

### 工作流程概要

1. **分解场景** - 将脚本拆分为视觉场景单元
2. **生成镜头描述** - 为每个场景创建详细的镜头说明
3. **创建视觉分镜** - 制作包含时间、镜头类型、描述的分镜表
4. **规划B-roll** - 列出补充画面的拍摄清单
5. **设计转场效果** - 规划场景间的过渡和视觉元素

### 常见陷阱

- 镜头过多导致剪辑过度
- 忽视连续性（服装、道具、灯光）
- B-roll与内容不匹配
- 缺少建立镜头

### 专业建议

- 3秒规则：每3秒改变画面元素
- 分层视觉：主持人+背景+叠加+动画
- 同时规划音频分镜
- 为横屏和竖屏同时规划
