# Multi-Platform Publishing Skill

> Distribute video content efficiently across multiple platforms.

## When to Use

- Publishing the same video to multiple platforms
- Adapting content for different platform requirements
- Building a multi-platform presence
- Maximizing reach from a single production effort
- Automating distribution workflows
- Tracking performance across platforms

## Workflow

### Step 1: Platform Matrix

```markdown
Plan your multi-platform distribution:

CONTENT: [video title/description]

PLATFORM MATRIX:
| Platform | Format | Aspect | Length | Status |
|----------|--------|--------|--------|--------|
| YouTube | Long-form | 16:9 | Full | Primary |
| YouTube Shorts | Clip | 9:16 | 60s | Repurpose |
| TikTok | Clip | 9:16 | 60s | Repurpose |
| Instagram Reels | Clip | 9:16 | 90s | Repurpose |
| Instagram Feed | Clip | 1:1 | 60s | Repurpose |
| LinkedIn | Clip | 16:9/1:1 | 3min | Professional |

- Each platform needs unique intro/hook

```

### Step 2: Content Adaptation

```markdown
Adapt content for each platform:

YOUTUBE → SHORTS/REELS/TIKTOK:
1. Identify the most engaging 60-second segment
2. Re-edit for vertical (9:16)
3. Add bold text overlays
4. Add captions (burned in)
5. Create platform-specific hook
6. Use trending audio if applicable

YOUTUBE → LINKEDIN:
1. Extract professional/educational segment
2. Add LinkedIn-friendly intro (more formal)
3. Write professional caption with takeaways
4. Include industry-relevant hashtags
5. Tag relevant people/companies

YOUTUBE → TWITTER/X:
1. Create 2:20 teaser or key moment
2. Write thread with key points
3. Include link to full video
4. Use relevant trending hashtags
5. Pin tweet if important

YOUTUBE → PODCAST:
1. Extract audio track
2. Add podcast intro/outro
3. Clean up audio (remove visual references)
4. Add podcast-specific CTA
5. Submit to podcast platforms
```

### Step 3: Scheduling Strategy

```markdown
Optimal posting schedule per platform:

YOUTUBE:
- Best days: Tuesday, Thursday, Saturday

- Frequency: 1-2x per week
- Strategy: Consistent schedule builds habit

TIKTOK:
- Best days: Tuesday, Thursday, Friday
- Best times: 7-9 AM, 12-3 PM, 7-11 PM
- Frequency: 1-3x per day (minimum 1x/day)
- Strategy: Volume + consistency

INSTAGRAM:
- Best days: Monday, Wednesday, Friday
- Best times: 11 AM - 1 PM, 7-9 PM
- Frequency: 1 Reel/day, 3-5 Stories/day
- Strategy: Reels for discovery, Stories for engagement

- Best days: Tuesday, Wednesday, Thursday
- Best times: 7-8 AM, 12 PM, 5-6 PM
- Frequency: 2-3x per week
- Strategy: Professional insights, less frequent

CROSS-PLATFORM TIMING:
Publish on original platform first, then distribute:
1. YouTube (primary): Day 1, 2 PM
2. Shorts/Reels/TikTok: Day 1-2 (clips)
3. LinkedIn/Twitter: Day 2 (professional angle)
4. Facebook: Day 2-3 (community focus)
5. Podcast: Day 3-4 (audio version)
```

## Pitfalls

### Common Mistakes

1. **Exact same post everywhere** - Each platform needs format adaptation
2. **Posting simultaneously** - Stagger posts for platform-specific timing
3. **Ignoring platform culture** - TikTok != LinkedIn; adjust tone
4. **No platform-specific CTA** - "Subscribe" doesn't work on TikTok
5. **Watermark sharing** - TikTok watermarks get penalized on Reels
6. **Over-automating** - Some things need human touch
7. **Spreading too thin** - Better to dominate 2 platforms than be mediocre on 7

### Quality Checks

- [ ] Content is adapted for each platform's format
- [ ] Hooks are platform-appropriate
- [ ] No watermarks from other platforms
- [ ] Hashtags are platform-specific
- [ ] CTAs are platform-appropriate
- [ ] Posting times are optimized per platform
- [ ] Links work on all platforms

## Pro Tips

1. **Download without watermark** - Use SnapTik or similar for clean reposts
2. **Platform-first creation** - Create natively when possible, not always repurpose
3. **Test hooks per platform** - Same video, different hooks, see what works
4. **The 80/20 rule** - 80% effort on your primary platform, 20% on others
5. **Use platform tools** - Native features (stickers, polls) boost reach
6. **Batch by platform** - Dedicate days to each platform's unique content
7. **Track attribution** - Use UTM links to know which platform drives traffic

## 中文版本

### 何时使用

- 将同一视频发布到多个平台
- 为不同平台需求调整内容
- 建立多平台存在
- 从单次制作中最大化覆盖
- 自动化分发工作流程
- 跟踪跨平台表现

### 工作流程概要

1. **平台矩阵** - 确定每个平台的格式、比例、时长要求
2. **内容适配** - 为每个平台重新编辑和调整内容
3. **发布时间策略** - 每个平台的最佳发布时间和频率
4. **自动化工具** - Buffer、Later、Repurpose.io等
5. **性能跟踪** - 跨平台指标仪表板和分析

### 常见陷阱

- 所有平台发完全相同的内容
- 同时发布（应错开时间）
- 忽视平台文化差异
- 水印跨平台分享
- 摊子铺得太薄

### 专业建议

- 无水印下载
- 原生创建优先
- 每个平台测试不同钩子
- 80/20法则：主平台80%精力
- 使用平台原生工具
