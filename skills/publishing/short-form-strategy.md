# Short-Form Strategy Skill

> Create viral short-form content for TikTok, Reels, and YouTube Shorts.

## When to Use

- Creating content for TikTok, Instagram Reels, or YouTube Shorts
- Repurposing long-form content into short clips
- Building audience through short-form discovery
- Testing content ideas before investing in long-form
- Following trends and formats on social platforms
- Growing followers through algorithm-friendly content

## Workflow

### Step 1: Platform Strategy

```markdown
Define your short-form content strategy:

PRIMARY PLATFORM: [TikTok / Reels / Shorts]
GOAL: [followers / views / traffic / brand awareness]
POSTING FREQUENCY: [1x/day / 2x/day / 3x/week]
CONTENT MIX: [original / repurposed / trending]

PLATFORM DIFFERENCES:

TIKTOK:
- Algorithm: Interest-based, not follower-based
- Best length: 15-60 seconds (sweet spot)
- Trends: Fast-moving, audio-driven
- Discovery: For You Page (FYP)
- Key: Hook in 1 second, trend participation

INSTAGRAM REELS:
- Algorithm: Follower + discovery hybrid
- Best length: 15-30 seconds
- Trends: Slower than TikTok, more polished
- Discovery: Explore page + feed
- Key: High production value, shareable

YOUTUBE SHORTS:
- Algorithm: Suggested + Shorts feed
- Best length: 30-60 seconds
- Trends: Cross-platform trends
- Discovery: Shorts shelf + search
- Key: Strong hook, complete story
```

### Step 2: Hook Engineering

```markdown
Create hooks that stop the scroll:

HOOK FRAMEWORK (first 1-3 seconds):

TYPE 1: PATTERN INTERRUPT
- Unexpected visual
- Bold statement
- Controversial opinion
- "Wait, watch this..."

TYPE 2: CURIOSITY GAP
- "The one thing nobody tells you about..."
- "I tried [X] for 30 days..."
- "Here's why [common belief] is wrong"

TYPE 3: DIRECT BENEFIT
- "Here's how to [achieve result]"
- "3 tips that [benefit]"
- "You need to know this about [topic]"

TYPE 4: SOCIAL PROOF
- "This changed my life"
- "I wish I knew this sooner"
- "Everyone is doing this wrong"

HOOK ELEMENTS:
- [ ] Visual hook (something unexpected on screen)
- [ ] Audio hook (engaging voice/music)
- [ ] Text hook (on-screen text overlay)
- [ ] Emotional hook (curiosity/fear/excitement)
```

### Step 3: Content Formats

```markdown
Short-form content format library:

FORMAT 1: QUICK TIP
- Duration: 15-30 seconds
- Structure: Hook → Tip → CTA
- Example: "3 keyboard shortcuts you didn't know"
- Works for: Education, productivity, tech

FORMAT 2: BEFORE/AFTER
- Duration: 15-30 seconds
- Structure: Before → Transition → After
- Example: "Room transformation in 60 seconds"
- Works for: DIY, fitness, design, cooking

FORMAT 3: TRENDING AUDIO
- Duration: 15-60 seconds
- Structure: Trend setup → Your twist → Punchline
- Example: Using trending sound with niche content
- Works for: Brand building, entertainment

FORMAT 4: STORYTIME
- Duration: 30-60 seconds
- Structure: Hook → Story → Lesson
- Example: "How I got 100K followers in 30 days"
- Works for: Personal brand, education

FORMAT 5: LISTICLE
- Duration: 30-60 seconds
- Structure: "X things..." → Quick reveals → Recap
- Example: "5 apps that changed my workflow"
- Works for: Reviews, recommendations, tips

FORMAT 6: REACTION/COMMENTARY
- Duration: 15-60 seconds
- Structure: Show content → React → Add value
- Example: Reacting to viral videos in your niche
- Works for: Entertainment, education, engagement
```

### Step 4: Production

```markdown
Short-form production checklist:

FILMING:
- [ ] Vertical orientation (9:16)
- [ ] Good lighting (ring light or window)
- [ ] Clear audio (lapel mic or phone close)
- [ ] Steady shot (tripod or stable surface)
- [ ] Clean background (or relevant environment)

EDITING:
- [ ] Fast pacing (cut every 2-3 seconds)
- [ ] Text overlays on screen
- [ ] Trending audio or clear voiceover
- [ ] Captions (80% watch without sound)
- [ ] Visual effects/transitions (subtle, not distracting)
- [ ] End screen that loops or CTA

POSTING:
- [ ] Optimal hashtags (3-5 relevant, not 30)
- [ ] Engaging caption (question or CTA)
- [ ] Post at peak hours (check analytics)
- [ ] Reply to comments quickly
- [ ] Share to stories
```

### Step 5: Growth Tactics

```markdown
Short-form growth strategies:

ALGORITHM HACKS:
1. **Post consistently** - Same time every day
2. **First hour engagement** - Reply to every comment
3. **Watch time is king** - Keep viewers watching to the end
4. **Loop trick** - Make ending flow into beginning
5. **Series content** - "Part 1" creates binge behavior

ENGAGEMENT TACTICS:
1. Ask a question in every video
2. Create "save-worthy" content (tips, tutorials)
3. Use controversial (but respectful) takes
4. Duet/Stitch with larger creators
5. Reply to comments with video responses

CROSS-PLATFORM:
1. Post same content on all platforms (adjust format)
2. Use each platform's native tools
3. Drive traffic between platforms
4. Adapt hooks for each audience
5. Test which platform works best for your content
```

## Pitfalls

### Common Mistakes

1. **Long intros** - You have 1 second to hook; no "Hey guys..."
2. **Too much text** - Short-form is visual-first
3. **No captions** - 80% watch without sound
4. **Ignoring trends** - Trends are the growth hack
5. **Posting once a week** - Algorithm needs daily consistency
6. **Same content as long-form** - Short-form needs different pacing and energy
7. **No CTA** - Tell viewers what to do next

### Quality Checks

- [ ] Hook happens in first 1-3 seconds?
- [ ] Video is under 60 seconds?
- [ ] Captions are on screen?
- [ ] Pacing is fast enough (cut every 2-3 seconds)?
- [ ] Has a clear CTA or loop?
- [ ] Optimized for mobile viewing?

## Pro Tips

1. **Batch create** - Film 10 shorts in one session
2. **The loop trick** - Make the last frame flow into the first
3. **Text is king** - Bold, readable text overlay on every video
4. **Trending sounds** - Use trending audio even under original content
5. **Part strategy** - "Part 1" series creates binge behavior
6. **Reply with video** - Turn comments into new content
7. **Cross-post strategically** - Same content, platform-specific hooks

## 中文版本

### 何时使用

- 为TikTok、Instagram Reels或YouTube Shorts创建内容
- 将长视频内容重新剪辑为短视频
- 通过短视频发现机制建立受众
- 在投入长视频前测试内容想法
- 跟随社交平台的趋势和格式
- 通过算法友好的内容增长粉丝

### 工作流程概要

1. **平台策略** - TikTok、Reels、Shorts的差异和最佳实践
2. **钩子工程** - 模式中断、好奇心缺口、直接利益、社交证明
3. **内容格式** - 快速提示、前后对比、趋势音频、故事、列表
4. **制作** - 竖屏、快速剪辑、文字叠加、字幕
5. **增长策略** - 算法技巧、互动策略、跨平台分发

### 常见陷阱

- 冗长的开场
- 文字过多
- 没有字幕
- 忽视趋势
- 每周只发一次

### 专业建议

- 批量创建：一次拍摄10个短视频
- 循环技巧：结尾流畅过渡到开头
- 文字为王：每个视频都加粗体可读文字
- 使用趋势音频
- "第X部分"系列创造连续观看
