# Screen Recording Skill

> Create polished, professional screen recordings for tutorials and demos.

## When to Use

- Recording software tutorials and walkthroughs
- Creating product demo videos
- Building online course content
- Documenting technical processes
- Recording coding sessions or live demonstrations
- Creating troubleshooting guides

## Workflow

### Step 1: Pre-Recording Setup

```markdown
Prepare for screen recording:

SYSTEM CHECKLIST:
- [ ] Close unnecessary applications and notifications
- [ ] Clean desktop (hide icons or use clean wallpaper)
- [ ] Set screen resolution (1920x1080 minimum, 2560x1440 preferred)
- [ ] Increase cursor size for visibility
- [ ] Set system dark/light mode to match content
- [ ] Clear browser bookmarks bar
- [ ] Disable notification popups (Focus Assist / Do Not Disturb)
- [ ] Set up virtual desktop with clean workspace
- [ ] Test microphone levels
- [ ] Prepare demo data (no real personal info)
```

### Step 2: Script and Outline

```markdown
Create a screen recording outline:

SOFTWARE: [app/website name]
TASK: [what you're demonstrating]
VIEWER LEVEL: [beginner / intermediate / advanced]

Outline:
1. Introduction (what they'll learn, 30 seconds)
2. Prerequisites (what they need, 30 seconds)
3. Main walkthrough (step by step, X minutes)
4. Common mistakes / troubleshooting (1-2 minutes)
5. Summary and next steps (30 seconds)

For each step, specify:
- Exact clicks/menus to navigate
- What to say during this action
- Zoom/highlight moments
- Speed adjustments (normal / slow / 2x speed)
```

### Step 3: Recording Best Practices

```markdown
Recording checklist:

CURSOR & INTERACTIONS:
- [ ] Enable cursor highlighting (colored ring/circle)
- [ ] Use click indicators (ripple effect on click)
- [ ] Slow down cursor movements
- [ ] Pause 1-2 seconds after each action
- [ ] Use keyboard shortcuts where visible

AUDIO:
- [ ] Narrate what you're doing (not just what's on screen)
- [ ] Explain WHY, not just HOW
- [ ] Pause recording if you need to think
- [ ] Maintain consistent distance from microphone

VISUAL:
- [ ] Zoom into important areas (2x minimum for small text)
- [ ] Highlight/spotlight key areas before clicking
- [ ] Use annotation tools in real-time if available
- [ ] Record at native resolution, crop in post
```

### Step 4: Post-Production

```markdown
Post-production checklist for screen recordings:

EDITING:
- [ ] Remove all mistakes, "ums", and dead air
- [ ] Speed up repetitive actions (2-4x with speed ramp)
- [ ] Add zoom-ins on key actions
- [ ] Insert text callouts for important steps
- [ ] Add cursor highlight effects if not done live
- [ ] Color correct if needed

ENHANCEMENTS:
- [ ] Add intro title card (3-5 seconds)
- [ ] Add chapter markers for each major step
- [ ] Include keyboard shortcut overlays
- [ ] Add progress bar or step counter
- [ ] Insert "Pro Tip" callouts
- [ ] Add background music (low, non-distracting)

EXPORT:
- [ ] Resolution: 1080p minimum (1440p/4K for code)
- [ ] Frame rate: 30fps (60fps for fast interactions)
- [ ] Codec: H.264 or H.265
- [ ] Check text readability at target resolution
```

### Step 5: Accessibility

```markdown
Make screen recordings accessible:

- [ ] Add captions/subtitles
- [ ] Ensure sufficient color contrast
- [ ] Don't rely solely on color to convey information
- [ ] Describe visual elements verbally
- [ ] Provide text transcript
- [ ] Use large enough text overlays (minimum 24pt)
```

## Templates

### Tutorial Screen Recording Script

```markdown
# [Software] Tutorial: [Task]

## Recording Settings
- Resolution: [1920x1080 / 2560x1440]
- Frame rate: 30fps
- Audio: [Mic name] at [distance]
- Cursor highlight: [color/size]

## Scene Plan
| # | Section | Duration | Zoom? | Speed | Notes |
|---|---------|----------|-------|-------|-------|
| 1 | Intro | 0:00-0:30 | No | 1x | Show final result first |
| 2 | Setup | 0:30-1:30 | Yes | 1x | Highlight preferences |
| 3 | Main task | 1:30-5:00 | Yes | 1x-2x | Key areas zoomed |
| 4 | Tips | 5:00-6:00 | Yes | 1x | Error scenarios |
| 5 | Result | 6:00-6:30 | No | 1x | Show final output |
```

### Quick Demo Recording Template

```markdown
# Quick Demo: [Feature Name]
# Duration: < 2 minutes
# Format: [GIF / MP4 / Loom]

## Beat Sheet
1. **Open** (3s): Show the finished result
2. **Problem** (10s): What's annoying about the old way
3. **Solution** (30s): Walk through the new feature
4. **Highlight** (10s): Zoom on the magic moment
5. **Result** (7s): Show the outcome

## Recording Notes
- [ ] Background app: [relevant app only]
- [ ] Zoom level: [100% / 150% / 200%]
- [ ] Annotations: [cursor highlight / arrow / circle]
```

## Pitfalls

### Common Mistakes

1. **Recording at low resolution** - Always record at highest possible resolution
2. **Mouse wandering** - Keep cursor still when not actively clicking
3. **No zoom on details** - Small UI elements are invisible on mobile viewers
4. **Monotone narration** - Sound engaged, explain the "why" not just "what"
5. **Too fast** - New viewers need more processing time than you think
6. **Showing real data** - Use demo accounts, never show personal information
7. **No chapters** - Long tutorials without chapters frustrate viewers

### Quality Checks

- [ ] Can you read all text at 720p playback?
- [ ] Is cursor movement smooth and purposeful?
- [ ] Are all steps audible and clear?
- [ ] No personal information or notifications visible?
- [ ] Does zooming highlight the right areas?
- [ ] Is the recording under 2x the target length?

## Pro Tips

1. **Record twice** - First as practice, second for final (saves editing time)
2. **Use a script** - Even bullet points prevent rambling
3. **1080p at 150% zoom** - Record 1080p with UI scaled to 150% for readability
4. **Color your cursor** - Yellow or red cursor highlight on dark backgrounds
5. **Pre-build the demo** - Have steps pre-loaded so you can show smooth transitions
6. **Separate audio tracks** - Record system audio and mic on separate tracks
7. **Speed ramp boring parts** - 2-4x for setup/navigation, 1x for key actions

## 中文版本

### 何时使用

- 录制软件教程和演示
- 创建产品演示视频
- 制作在线课程内容
- 记录技术流程
- 录制编程会话或现场演示
- 创建故障排除指南

### 工作流程概要

1. **录制前准备** - 系统检查、清理桌面、测试设备
2. **脚本和大纲** - 创建分步录制大纲
3. **录制最佳实践** - 光标高亮、缩放、叙述
4. **后期制作** - 编辑、增强、导出
5. **无障碍性** - 添加字幕、确保对比度

### 常见陷阱

- 低分辨率录制
- 鼠标游移不定
- 未对细节进行缩放
- 语调单调
- 展示真实个人数据

### 专业建议

- 录制两次：第一次练习，第二次正式
- 使用脚本防止漫无目的
- 1080p分辨率配合150%缩放
- 为光标设置醒目颜色
- 分离音频轨道录制
