# Thumbnail Creation Skill

> Design click-worthy thumbnails that maximize video CTR.

## When to Use

- Creating thumbnails for new YouTube videos
- A/B testing thumbnail designs
- Refreshing thumbnails on underperforming videos
- Designing thumbnails for shorts and social media
- Building thumbnail templates for series content
- Analyzing competitor thumbnail strategies

## Workflow

### Step 1: Thumbnail Strategy

```markdown
Plan your thumbnail before designing:

VIDEO TITLE: [your video title]
SEARCH INTENT: [what the viewer is looking for]
KEY EMOTION: [curiosity / excitement / fear / surprise / value]
COMPETITION: [what other thumbnails look like for this topic]

THUMBNAIL RULES:
1. Must be understandable at 1 inch (mobile size)
2. Maximum 3-4 words of text
3. One clear focal point
4. High contrast (readable on light and dark backgrounds)
5. Faces get 30-40% more clicks (when relevant)
6. Curiosity gap: show enough to intrigue, not enough to satisfy
```

### Step 2: Design Layout

```markdown
Thumbnail layout templates:

LAYOUT A: SPLIT SCREEN
```
┌──────────────┬──────────────┐
│              │              │
│   [Image/    │  [Image/     │
│    Face]     │   Product]   │
│              │              │
│              │  [TEXT]      │
└──────────────┴──────────────┘
```
Best for: Before/after, comparisons, reveals

LAYOUT B: FULL BLEED WITH TEXT
```
┌──────────────────────────┐
│                          │
│    [Full background      │
│     image]               │
│                          │
│    [LARGE TEXT]           │
│    [subtitle]            │
└──────────────────────────┘
```
Best for: Tutorials, storytelling, vlogs

LAYOUT C: SUBJECT + ELEMENTS
```
┌──────────────────────────┐
│ [Emoji/  [Subject/       │
│  Icon]    Face/Person]   │
│                          │
│ [Arrow →] [TEXT]         │
│                          │
└──────────────────────────┘
```
Best for: How-to, lists, reactions
```

### Step 3: Design Execution

```markdown
Create thumbnail in Canva/Photoshop:

CANVAS SIZE: 1280x720px (16:9) - YouTube standard
DPI: 72 (web only)
FORMAT: PNG or JPG (under 2MB)

DESIGN CHECKLIST:
- [ ] Background: Simple, not cluttered
- [ ] Subject: Large and clear (40-60% of frame)
- [ ] Text: 2-4 words, bold, contrasting colors
- [ ] Text size: Readable when thumbnail is 1 inch wide
- [ ] Faces: Expressive emotion, eyes visible
- [ ] Colors: 2-3 max, high saturation for pop
- [ ] Arrows/circles: Only if they add clarity
- [ ] Border: Optional 5px outline for definition

COLOR COMBINATIONS THAT POP:
- Yellow + Black (high contrast)
- Red + White (urgent, attention-grabbing)
- Blue + Yellow (YouTube brand synergy)
- Green + White (money/success topics)
- Purple + Yellow (creative/unique)
```

### Step 4: AI-Assisted Design

```markdown
Use AI for thumbnail creation:

BACKGROUND REMOVAL:
- Remove.bg (free, automatic)
- Photoshop Select Subject
- Canva Background Remover

AI IMAGE GENERATION:
Prompt: "YouTube thumbnail background for [topic],
hyper-realistic, dramatic lighting, vibrant colors,
8K, cinematic, [specific elements]"

TEXT GENERATION:
- Use AI to brainstorm 10 text options
- Then pick the most curiosity-inducing 2-4 words

FACE EXPRESSIONS:
- Generate multiple expressions
- Select the most emotionally compelling
```

### Step 5: A/B Testing

```markdown
Thumbnail A/B testing process:

CREATE VARIATIONS:
1. Design 2-3 different thumbnail concepts
2. Each should test ONE variable:
   - Different text
   - Different image
   - Different color scheme
   - With/without face
   - Different layout

TEST PROCESS:
1. Upload Version A
2. After 48 hours, check CTR in YouTube Analytics
3. Replace with Version B
4. Compare CTR after same time period
5. Winner stays; create new challenger

METRICS TO WATCH:
- CTR (Click-Through Rate): Aim for 5-10%+
- Average: 2-10% depending on niche
- Top performers: 10%+ CTR
- Below 4%: Needs improvement
```

```markdown
# Thumbnail Review Checklist

## Readability (3-second test)
- [ ] Text readable at 1 inch width?
- [ ] Clear on both light and dark backgrounds?
- [ ] Works on mobile (320px wide)?

## Composition
- [ ] Single focal point?
- [ ] Rule of thirds applied?
- [ ] Negative space used effectively?
- [ ] No important elements at edges (safe margins)?

- [ ] Evokes curiosity or emotion?
- [ ] Creates information gap?
- [ ] Faces show clear emotion?

- [ ] 1280x720px resolution?
- [ ] Under 2MB file size?
- [ ] High contrast colors?
- [ ] No copyright issues?
```

## Pitfalls

### Common Mistakes

1. **Too much text** - More than 4 words is too many for thumbnails
2. **Small subject** - The main element should dominate the frame
3. **Boring colors** - Muted, low-contrast thumbnails get skipped
4. **Clickbait without payoff** - Overpromising hurts retention
5. **Ignoring mobile** - Most views are on phones; think small
6. **Cluttered design** - Too many elements confuse the viewer
7. **No testing** - One thumbnail design is not enough

### Quality Checks

- [ ] Can you understand the thumbnail in under 2 seconds?
- [ ] Is it clear what the video is about?
- [ ] Does it stand out in a grid of competing thumbnails?
- [ ] Would YOU click on this thumbnail?
- [ ] Does it accurately represent the video content?

## Pro Tips

1. **The squint test** - Squint at your thumbnail; can you still read it?
2. **Study Mr. Beast** - His thumbnails are A/B tested to perfection
3. **Bright backgrounds** - Lighter thumbnails outperform darker ones on average
4. **Yellow is king** - Yellow elements consistently get higher CTR
5. **Update old thumbnails** - A new thumbnail can revive a dead video
6. **Consistency builds brand** - Use similar style across your videos
7. **Time of day test** - Upload at different times to see CTR impact

## 中文版本

### 何时使用

- 为新YouTube视频创建缩略图
- A/B测试缩略图设计
- 刷新表现不佳视频的缩略图
- 为短视频和社交媒体设计缩略图
- 为系列内容构建缩略图模板
- 分析竞争对手缩略图策略

### 工作流程概要

1. **缩略图策略** - 明确搜索意图、关键情感、竞争环境
2. **设计布局** - 分屏、全出血、主体+元素三种模板
3. **设计执行** - 画布尺寸、检查清单、颜色搭配
4. **AI辅助** - 背景移除、AI图像生成、文字生成
5. **A/B测试** - 创建变体、对比CTR、迭代优化

### 常见陷阱

- 文字过多
- 主体太小
- 颜色平淡
- 误导性标题党
- 忽视移动端

### 专业建议

- 眯眼测试：眯眼看还能读懂吗
- 研究Mr. Beast的缩略图
- 亮色背景通常优于暗色
- 黄色元素CTR最高
- 更新旧缩略图可以复活视频
