# Video Editing Skill

> Edit videos efficiently with professional techniques and AI-assisted workflows.

## When to Use

- Editing raw footage into polished videos
- Cutting and arranging multi-camera footage
- Color grading and visual correction
- Adding transitions, effects, and graphics
- Syncing audio and video from separate sources
- Creating fast-paced social media edits

### Step 2: Assembly Edit (Rough Cut)

```markdown
Create the rough cut:

1. IMPORT & SYNC
   - Import all footage and audio
   - Sync multi-cam using audio waveform or timecode
   - Create multicam sequence if applicable

2. SELECT BEST TAKES
   - Review all footage and mark selects
   - Use keyboard shortcuts for fast review (J/K/L)
   - Mark in/out points for usable sections

3. ROUGH ASSEMBLY
   - Place selects on timeline in script order
   - Don't worry about exact timing yet
   - Focus on content flow and story structure
   - Leave gaps for B-roll placement

4. FIRST REVIEW
   - Watch the rough cut start to finish
   - Note where pacing drags
   - Identify sections needing additional footage
   - Check that story/message is clear
```

### Step 3: Fine Edit

```markdown
Refine the edit:

PACING:
- Remove all "ums", "uhs", and verbal stumbles
- Cut dead air to 0.3-0.5 seconds (natural pause)
- Tighten transitions between sentences
- Vary shot lengths (3-8 seconds average)
- Speed up 1.5-2x for repetitive or slow sections

J-CUTS AND L-CUTS:
- J-Cut: Audio from next clip starts before video
- L-Cut: Audio from current clip continues into next
- Use for natural conversation flow
- Use for smooth topic transitions

B-ROLL INTEGRATION:
- Add B-roll over narration-heavy sections
- Match B-roll content to what's being discussed
- Use 3-5 second B-roll clips minimum
- Layer multiple B-roll clips for visual variety

SOUND DESIGN:
- Sync all audio sources
- Apply noise reduction if needed
- Add music beds (low, under narration)
- Add sound effects for transitions
- Normalize audio levels (-16 LUFS for YouTube)
```

### Step 4: Color Grading

```markdown
Color grading workflow:

1. COLOR CORRECTION (fix issues)
   - White balance: Match across all clips
   - Exposure: Bring all clips to consistent brightness
   - Contrast: Set black and white points
   - Saturation: Normalize color intensity

2. COLOR GRADING (creative look)
   - Apply a base LUT
   - Adjust highlights (warm/cool)
   - Adjust shadows (warm/cool)
   - Fine-tune midtones
   - Add subtle film grain if desired

3. SKIN TONES
   - Use vectorscope to check skin tones
   - Skin should fall on the skin tone line
   - Avoid over-saturating skin
   - Qualify skin tones for isolated adjustments

4. MATCH ACROSS SHOTS
   - Use comparison view between shots
   - Apply shot-to-shot corrections
   - Use adjustment layers for scene-wide changes
```

### Step 5: Export Settings

```markdown
Export presets:

YOUTUBE (Recommended):
- Resolution: 1080p or 4K
- Codec: H.264 (or H.265 for 4K)
- Bitrate: 16-24 Mbps (1080p) / 45-68 Mbps (4K)
- Frame rate: Match source
- Audio: AAC, 320kbps, Stereo

TIKTOK / REELS / SHORTS:
- Resolution: 1080x1920 (9:16)
- Codec: H.264
- Bitrate: 10-15 Mbps
- Duration: 15-60 seconds
- Audio: AAC, 256kbps

LINKEDIN / TWITTER:
- Resolution: 1080x1080 (1:1) or 1920x1080 (16:9)
- Codec: H.264
- Bitrate: 10-15 Mbps
- Duration: Under 10 minutes
```

## Pitfalls

### Common Mistakes

1. **Jump cuts without motivation** - Use J/L cuts or B-roll to hide cuts
2. **Audio levels inconsistent** - Normalize everything to -16 LUFS
3. **Too many effects** - Transitions and effects should be invisible, not flashy
4. **Ignoring audio** - Bad audio is more noticeable than bad video
5. **Not color matching** - Different cameras need color correction to match
6. **Exporting wrong format** - Each platform has specific requirements
7. **Saving over project files** - Use versioned saves (v1, v2, v3)

### Quality Checks

- [ ] Audio is normalized and clean
- [ ] No jump cuts without B-roll coverage
- [ ] Color is consistent across all shots
- [ ] Music doesn't overpower voice
- [ ] All text is legible at 1080p
- [ ] Video length matches target
- [ ] Export settings match platform requirements

## Pro Tips

1. **Edit audio first** - Get the story right in audio-only, then add visuals
2. **Learn keyboard shortcuts** - They 10x your editing speed
3. **Use adjustment layers** - Apply effects to entire sections non-destructively
4. **Match frame rate** - Always export at the same frame rate you shot
5. **Proxy editing** - Edit with low-res proxies, export from high-res originals
6. **Auto-save every 5 minutes** - Crash protection is essential
7. **Watch on multiple devices** - Check phone, tablet, and desktop before finalizing

## 中文版本

### 何时使用

- 将原始素材编辑成精美视频
- 剪辑和排列多机位素材
- 调色和视觉校正
- 添加转场、特效和图形
- 同步不同来源的音频和视频
- 创建快节奏社交媒体编辑

### 工作流程概要

1. **素材组织** - 项目结构、命名规范、标签系统
2. **粗剪** - 导入同步、选择最佳片段、初步排列
3. **精剪** - 调整节奏、J/L剪辑、整合B-roll、音效设计
4. **调色** - 色彩校正、创意调色、肤色处理、镜头匹配
5. **导出** - 根据平台选择正确设置

### 常见陷阱

- 无动机的跳切
- 音频电平不一致
- 特效过多
- 忽视音频质量
- 不同镜头色彩不匹配

### 专业建议

- 先剪音频再加画面
- 学习键盘快捷键
- 使用调整图层
- 使用代理编辑
- 在多种设备上预览
