# 🎬 Awesome Video Creation

> **アイデアから公開動画まで数時間で。完全なワークフローをカバーする 14 の AI スキル。**

クリエイティブな企画からマルチプラットフォーム公開までの完全な動画制作ワークフロー向けの AI スキルキュレーションコレクション。各スキルは、ワークフロー、ツール、テンプレート、実績のあるパターンを含む完全なガイドです。

## 概要

優れた動画を作成するには、録画ボタンを押すだけでは不十分です。このリポジトリは、動画制作プロセスのあらゆる段階をカバーする **5 つのカテゴリ**に整理された **14 の実践済みスキル**を提供します。

ソロクリエイターでも、小さなチームでも、大規模な組織の一員でも、これらのスキルは以下を支援します：

- **コンテンツ企画** — 観客の心に響くコンテンツの企画
- **撮影** — プロフェッショナルに見える・聞こえる映像の撮影
- **編集・仕上げ** — 効率的なワークフローで動画を編集・磨き上げ
- **オーディオデザイン** — 視聴体験を向上させるオーディオデザイン
- **戦略的公開** — すべてのプラットフォームで戦略的に公開

## 使い方

### はじめに

1. **スキルを閲覧** — 各スキルは独立したガイドです
2. **現在のニーズから開始** — 必要に応じて任意のスキルに飛びましょう
3. **ワークフローに従う** — 一貫した結果を得るためのステップバイステッププロセス
4. **テンプレートを使用** — 一般的なタスク用のすぐに使えるテンプレート
5. **落とし穴を確認** — ミスをする前によくある間違いから学ぶ

### 推奨学習パス

動画制作が初めての方は、この順序をお勧めします：

```
コンテンツ戦略 → 脚本執筆 → ストーリーボード →
トークヘッド/画面録画 → 動画編集 →
サムネイル作成 → YouTube 最適化 →
ショート動画戦略 → マルチプラットフォーム公開
```

### スキル構成

各スキルは一貫したフォーマットに従います：

```
├── 使用タイミング    # このスキルが適用される明確なトリガー
├── ワークフロー      # ステップバイステッププロセス（3〜5ステップ）
├── ツール            # 価格付き推奨ツール
├── テンプレート      # すぐに使えるテンプレートとチェックリスト
├── よくある落とし穴  # よくあるミスとその回避方法
└── プロのヒント      # 経験豊富なクリエイターからの上級テクニック
```
