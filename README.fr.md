# 🎬 Awesome Video Creation

> **De l'idée à la vidéo publiée en quelques heures, pas en semaines. 14 compétences IA couvrant le workflow complet.**

Une collection curatée de compétences IA pour le workflow complet de création vidéo — de la planification créative à la publication multiplateforme. Chaque compétence est un guide complet avec des workflows, des outils, des modèles et des éprouvés patterns.

## Aperçu

Créer de superbes vidéos implique bien plus que simplement appuyer sur le bouton d'enregistrement. Ce dépôt fournit **14 compétences éprouvées** organisées en **5 catégories** qui couvrent chaque étape du processus de création vidéo.

Que vous soyez un créateur solo, une petite équipe ou une organisation plus importante, ces compétences vous aideront à :

- **Planifier le contenu** qui résonne avec votre audience
- **Filmer des séquences** qui ont l'air et le son professionnels
- **Monter et peaufiner** les vidéos avec des workflows efficaces
- **Concevoir l'audio** qui améliore l'expérience de visionnage
- **Publier stratégiquement** sur toutes les plateformes

## Comment utiliser

### Pour commencer

1. **Parcourez les compétences** — Chaque compétence est un guide autonome
2. **Commencez où vous en êtes** — Accédez directement à la compétence dont vous avez besoin
3. **Suivez les workflows** — Des processus pas à pas pour des résultats cohérents
4. **Utilisez les modèles** — Des modèles prêts à l'emploi pour les tâches courantes
5. **Vérifiez les pièges** — Apprenez des erreurs courantes avant de les commettre

### Parcours d'apprentissage recommandé

Si vous débutez dans la création vidéo, nous recommandons cet ordre :

```
Stratégie de contenu → Rédaction de script → Storyboarding →
Talking Head/Capture d'écran → Montage vidéo →
Création de miniature → Optimisation YouTube →
Stratégie Short-Form → Publication multiplateforme
```

### Structure des compétences

Chaque compétence suit un format cohérent :

```
├── Quand l'utiliser    # Déclencheurs clairs pour l'application
├── Workflow            # Processus pas à pas (3-5 étapes)
├── Outils              # Outils recommandés avec tarification
├── Modèles             # Modèles et listes de contrôle prêts à l'emploi
├── Pièges courants     # Erreurs fréquentes et comment les éviter
└── Conseils pro        # Techniques avancées de créateurs expérimentés
```
