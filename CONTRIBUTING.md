# Contributing to Awesome Video Creation

Thank you for your interest in contributing! This project aims to be the best resource for AI-powered video creation workflows.

## How to Contribute

### Types of Contributions

1. **New Skills** - Propose or add new video creation skills
2. **Skill Improvements** - Enhance existing skills with better workflows, tools, or tips
3. **Bug Fixes** - Fix typos, broken links, or formatting issues
4. **Translations** - Add or improve Chinese/other language sections
5. **Tool Updates** - Update tool recommendations with new options or pricing

### Getting Started

1. **Fork** the repository
2. **Create** a feature branch (`git checkout -b feature/amazing-skill`)
3. **Make** your changes
4. **Test** your changes (check formatting, links work, etc.)
5. **Commit** with clear messages (`git commit -m 'Add amazing skill'`)
6. **Push** to your branch (`git push origin feature/amazing-skill`)
7. **Open** a Pull Request

### Skill File Structure

Each skill should follow this structure:

```markdown
# Skill Name

> One-line description of what this skill does.

## When to Use

- Trigger condition 1
- Trigger condition 2
- ...

## Workflow

### Step 1: [Action]
[Detailed instructions]

### Step 2: [Action]
[Detailed instructions]

[Continue for 3-5 steps]

## Tools

| Tool | Purpose | Price | Best For |
|------|---------|-------|----------|
| Tool 1 | ... | ... | ... |

## Templates

[Ready-to-use templates]

## Pitfalls

### Common Mistakes
1. Mistake 1
2. Mistake 2

### Quality Checks
- [ ] Check 1
- [ ] Check 2

## Pro Tips

1. Tip 1
2. Tip 2

## 中文版本

[Chinese summary of all sections]
```

### Style Guidelines

- **Language**: Write in clear, concise English
- **Tone**: Professional but approachable
- **Formatting**: Use Markdown consistently
- **Lists**: Use numbered lists for ordered items, bullets for unordered
- **Code blocks**: Use fenced code blocks for examples
- **Tables**: Use Markdown tables for structured data
- **Checkboxes**: Use `- [ ]` for actionable checklists
- **Length**: Each skill should be 150+ lines

### Content Guidelines

- **Actionable**: Every tip should be something the reader can do
- **Specific**: Prefer specific tools and techniques over general advice
- **Current**: Keep tool recommendations and pricing up to date
- **Balanced**: Include both free and paid options
- **Inclusive**: Consider creators of all skill levels

### Commit Messages

Use clear, descriptive commit messages:

```
Add: New skill for [topic]
Fix: Broken link in [skill name]
Update: Tool pricing for [tool name]
Improve: Workflow in [skill name]
Docs: Update README with new category
```

### Pull Request Process

1. **Describe** your changes in the PR description
2. **Link** to any related issues
3. **Check** that all links work
4. **Verify** formatting renders correctly
5. **Wait** for review (typically 2-3 days)

### Reporting Issues

When reporting issues, please include:

- **Description**: Clear description of the issue
- **Location**: Which skill file and section
- **Expected**: What you expected to see
- **Actual**: What actually happened
- **Screenshots**: If applicable
