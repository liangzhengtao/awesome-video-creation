# 🎬 Awesome Video Creation

[English](#overview) | [中文](#中文版本)

A curated collection of AI-powered skills for the complete video creation workflow — from creative planning to multi-platform publishing. Each skill is a comprehensive guide with workflows, tools, templates, and best practices.

## Overview

Creating great videos involves much more than just hitting record. This repository provides **14 battle-tested skills** organized into **5 categories** that cover every stage of the video creation process.

Whether you're a solo creator, a small team, or part of a larger organization, these skills will help you:

- **Plan content** that resonates with your audience
- **Record footage** that looks and sounds professional
- **Edit and polish** videos with efficient workflows
- **Design audio** that enhances the viewing experience
- **Publish strategically** across all platforms

## How to Use

### Getting Started

1. **Browse the skills** - Each skill is a standalone guide
2. **Start where you are** - Jump into any skill based on your current need
3. **Follow the workflows** - Step-by-step processes for consistent results
4. **Use the templates** - Ready-to-use templates for common tasks
5. **Check the pitfalls** - Learn from common mistakes before making them

### Recommended Learning Path

If you're new to video creation, we recommend this order:

```
Content Strategy → Script Writing → Storyboarding →
Talking Head/Screen Recording → Video Editing →
Thumbnail Creation → YouTube Optimization →
Short-Form Strategy → Multi-Platform Publishing
```
