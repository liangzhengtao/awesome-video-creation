# 🎬 精选视频创作指南

> **从创意到发布的视频，只需数小时而非数周。14项AI技能覆盖完整工作流程。**

这是一系列AI驱动的视频创作技能集合，涵盖从创意策划到多平台发布的完整流程。每项技能都是一份全面的指南，包含工作流程、工具推荐、模板和最佳实践。

## 概述

创建优质视频远不止按下录制键那么简单。本仓库提供 **14 项经过实战检验的技能**，分为 **5 大类别**，覆盖视频创作的每个阶段。

无论你是独立创作者、小团队，还是大型组织，这些技能都能帮助你：

- **策划内容** — 创作与观众产生共鸣的内容
- **拍摄素材** — 录制看起来和听起来都很专业的画面
- **剪辑打磨** — 使用高效的工作流程编辑和优化视频
- **音频设计** — 设计增强观看体验的音频
- **发布运营** — 在所有平台上进行战略性发布

## 使用方法

### 快速开始

1. **浏览技能库** — 每项技能都是独立的指南
2. **从当前需求开始** — 根据需要跳转到任何技能
3. **遵循工作流程** — 逐步执行，获得一致的结果
4. **使用模板** — 现成的模板和检查清单
5. **避开陷阱** — 在犯错前学习常见错误

### 推荐学习路线

如果你是视频创作新手，推荐按以下顺序学习：

```
内容策略 → 脚本撰写 → 故事板 →
面对镜头/屏幕录制 → 视频剪辑 →
缩略图设计 → YouTube优化 →
短视频策略 → 多平台发布
```

### 技能结构

每项技能遵循统一的格式：

```
├── 使用场景        # 明确的触发条件
├── 工作流程        # 逐步执行流程（3-5步）
├── 工具推荐        # 推荐工具及定价
├── 模板            # 现成的模板和检查清单
├── 常见陷阱        # 常见错误及如何避免
└── 专业技巧        # 来自资深创作者的高级技巧
```
