# 🎬 Awesome Video Creation

> **아이디어에서 게시된 영상까지 몇 시간, 몇 주가 아닌. 전체 워크플로를 다루는 14가지 AI 스킬.**

창작 기획부터 다중 플랫폼 배포까지 완전한 영상 제작 워크플로를 위한 AI 기반 스킬 큐레이션 컬렉션. 각 스킬은 워크플로, 도구, 템플릿, 검증된 패턴을 포함한 완전한 가이드입니다.

## 개요

훌륭한 영상을 만드는 것은 단순히 녹화 버튼을 누르는 것 이상의 많은 것을 필요로 합니다. 이 저장소는 영상 제작 프로세스의 모든 단계를 다루는 **5개 카테고리**로 정리된 **14개의 검증된 스킬**을 제공합니다.

솔로 크리에이터든, 소규모 팀이든, 대규모 조직의 일부이든, 이 스킬들은 다음과 같은 도움을 줍니다:

- **공감을 이끌어내는 콘텐츠 기획**
- **전문적으로 보이고 들리는 촬영**
- **효율적인 워크플로로 영상 편집 및 보완**
- **시청 경험을 향상시키는 오디오 설계**
- **모든 플랫폼에 걸친 전략적 배포**

## 사용 방법

### 시작하기

1. **스킬 둘러보기** - 각 스킬은 독립적인 가이드입니다
2. **현재 위치에서 시작** - 현재 필요에 따라 어떤 스킬이든 시작하세요
3. **워크플로 따르기** - 일관된 결과를 위한 단계별 프로세스
4. **템플릿 활용** - 일반 작업을 위한 바로 사용 가능한 템플릿
5. **함정 확인** - 실수하기 전에 흔한 실수에서 배우세요

### 추천 학습 경로

영상 제작 초보자라면 이 순서를 추천합니다:

```
콘텐츠 전략 → 대본 작성 → 스토리보딩 →
토킹 헤드/화면 녹화 → 영상 편집 →
썸네일 제작 → YouTube 최적화 →
숏폼 전략 → 다중 플랫폼 배포
```

### 스킬 구조

각 스킬은 일관된 형식을 따릅니다:

```
├── 사용 시점        # 이 스킬이 적용되는 명확한 트리거
├── 워크플로          # 단계별 프로세스 (3-5단계)
├── 도구             # 가격이 포함된 추천 도구
├── 템플릿           # 바로 사용 가능한 템플릿과 체크리스트
├── 함정             # 흔한 실수와 회피 방법
└── 프로 팁          # 숙련된 크리에이터의 고급 기법
```

## 대상 독자

- **솔로 유튜버** - 아이디어에서 게시된 영상까지 완전한 워크플로
- **콘텐츠 팀** - 일관된 품질을 위한 표준화된 프로세스

- **마케팅 팀** - 브랜드 구축을 위한 영상 콘텐츠

- **소셜 미디어 매니저** - 다중 플랫폼 영상 전략
